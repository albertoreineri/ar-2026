Working in a pleasant environment is key to productivity. Visual Studio Code has been gaining more and more popularity lately, and if you follow me you already know it's my editor of choice! Today let's look at my [favorite](https://albertoreineri.it/software-per-sviluppo-web/) themes for Visual Studio Code, both light and dark!

In 2019, [Visual Studio Code](https://code.visualstudio.com/) (VS Code) was the most used text editor among developers, with 50% of the 87,317 respondents using it. That was a big leap forward after being ranked 13th among popular development tools on Stack Overflow.

VS Code comes with a blazing-fast source code editor, ideal for everyday use. With support for hundreds of different programming languages, including C++, Java, JavaScript, JSON, Julia, PHP and more, it boosts your productivity with bracket matching, box selection, syntax highlighting, auto-indentation and more.

However, with over 5,000 themes to choose from, finding the best one for you can be daunting. If you're looking for the best VS Code themes to try, here are my favorites!

## **How to install themes in Visual Studio Code**

You can install themes in Visual Studio Code in two main ways. You can visit the Marketplace and select the theme you want to download, or you can search inside the VS Code IDE.

**Method 1: the Marketplace**

1: Visit the <a href="https://marketplace.visualstudio.com/vscode" target="_blank" rel="noreferrer noopener">Marketplace</a> and select the theme you want to download. In VS Code, click File > Preferences > Color Theme to open the color theme picker on Windows. On macOS, click Code > Preferences > Color Theme.

You can also open the picker using the keyboard shortcut "Ctrl+K Ctrl+T".

2: Use the arrow keys to scroll through and preview the theme colors.

3: Select the theme you want and press "Enter" on your keyboard.

<img src="https://www.tabnine.com/blog/wp-content/uploads/2021/11/1-how-to-install-vscode-themes-from-marketplace.png" class="wp-image-1588" decoding="async" />
</figure>

**Method 2: search within VS Code**

Alternatively, you can install a theme by searching for it inside VS Code. From the <a href="https://www.tabnine.com/blog/top-42-free-vscode-extensions/" target="_blank" rel="noreferrer noopener">Extensions</a> icon on the left side of VS Code, search for the theme you want and click Install.

## **Wrapping up**

VS Code is a great code editor that supports hundreds of languages and advanced features, including syntax highlighting, auto-indentation and snippets. It's well suited for modern web development and has an interactive debugger for viewing call stacks and running variables.
