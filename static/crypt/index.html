Encrypt & Decrypt Text Online

Encrypt and decrypt text right in your browser: nothing is sent to a server. Pick a mode:

  • Password · AES-256: real encryption. Use it for anything you want to protect.
  • Numeric key · XOR: a simple obfuscation. It's the original mode of this tool, so texts you encrypted here in the past can still be decrypted.

How this tool works

Password · AES-256

Your password is turned into a 256-bit key with PBKDF2 (SHA-256, 600,000 iterations and a random salt), and your text is encrypted with AES-256-GCM. The result is a single string that starts with aes1. and holds the salt, the nonce and the encrypted text. GCM also authenticates it: with a wrong password or an altered text, decryption fails instead of returning garbage. Everything uses your browser's built-in Web Crypto API, with no libraries.

Numeric key · XOR

Every character of your text is combined with the numeric key using the XOR operation. XOR is symmetric: applying the same key twice gives you back the original text, which is why encrypting and decrypting are the same operation. If you leave the key empty, the tool uses 1.

Everything runs in your browser, in a few lines of JavaScript you can read on GitHub. Your text, your password and your key are never sent to a server.

Is it secure?

Password · AES-256

Yes, within limits. AES-256-GCM is a standard, well-studied cipher, and the weak point is always the password: a short or common one can be guessed, so use a long passphrase and keep it somewhere safe. There is no recovery: if you lose the password, the text is gone. And like any tool that runs in the browser, it relies on the code this page serves you. For highly sensitive data, prefer an audited tool you run yourself, such as age or GnuPG.

Numeric key · XOR

No, and it isn't meant to be. A single-number XOR is obfuscation, not encryption: anyone who knows how it works can try every key in a fraction of a second. It's fine for hiding a spoiler, a puzzle or a note from a casual glance, and it's a nice way to see how XOR works.

FAQ

Which mode should I use?

Password mode for anything you want to protect. Numeric key mode only to hide something from a casual glance, or to decrypt texts from the earlier version of this tool.

I encrypted a text here in the past. How do I get it back?

Open the Numeric key · XOR tab (or go straight to albertoreineri.it/crypt/#xor), paste the text and enter the same key you used.

Can I decrypt an aes1. text with another tool?

Yes, the formats are standard. After the aes1. prefix, the text is base64 of the salt (16 bytes), the nonce (12 bytes) and the AES-256-GCM ciphertext with its 16-byte tag. The key comes from PBKDF2-HMAC-SHA256 with 600,000 iterations, and the word aes1 is used as additional authenticated data. The source on GitHub shows the details.

Why does the XOR text contain strange characters?

XOR can turn a letter into any other character, including symbols or invisible control characters. Use the copy button rather than selecting the text by hand, so nothing gets lost. AES results are plain letters and digits, so they copy and paste cleanly.

Can I decrypt a text without the password or the key?

With a strong password, not realistically. With XOR, trying keys one after another until the text becomes readable is usually quick.
